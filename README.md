# Adel Hasan — Personal Portfolio

Welcome to my personal portfolio website! 👋

I’m **Adel Hasan**, a Software Engineer passionate about building modern, responsive, and user-friendly websites and applications.

## 🚀 About the Project

This portfolio website was created to showcase my:

- Skills
- Projects
- Experience
- Services
- Contact information

The website is designed to be **responsive**, so it works across desktop, tablet, and mobile devices.

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Bootstrap
- Responsive Web Design

## ✨ Features

- Responsive design
- Modern and clean interface
- Navigation bar
- About section
- Skills section
- Projects section
- Services section
- Contact section
- Light/Dark mode
